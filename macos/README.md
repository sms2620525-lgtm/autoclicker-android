# TapBench 1.3.0 for macOS — 3개 지점 · 총 목표 40,000 CPS

macOS 13 이상, Apple Silicon과 Intel Mac을 지원하는 네이티브 오토클릭커입니다.

## 1.3.0 변경

- 클릭 지점을 최대 **3개**로 늘렸습니다. 기본값은 `3개 교대 / 고속 / 총 40,000 CPS / 10초`입니다. 1개와 2개도 선택할 수 있습니다.
- 1 → 2 → 3 → 1 순서로 반복 클릭합니다. macOS 포인터 하나를 세 위치에 순환시키는 방식이며, 세 포인터를 동시에 누르는 멀티터치는 아닙니다.
- 총 목표 속도와 입력 상한을 **40,000 CPS**로 올렸습니다. 세 지점 합계이며, 지점당 목표는 약 13,333 CPS입니다. 1k / 10k / 40k 버튼으로 빠르게 바꿀 수 있습니다.
- 세 번째 위치 지정 단축키 **Control + Option + F**를 추가했습니다. 위치 지정 버튼과 앱 메뉴도 세 지점을 지원합니다.
- 웹 측정 화면과 JSON/CSV v4에서 세 지점의 실제 수신 횟수와 합계 CPS를 확인할 수 있습니다.

## 사용

1. DMG를 열고 TapBench.app을 Applications로 드래그합니다.
2. 앱의 `권한 설정`을 누르고 시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용에서 TapBench를 허용합니다.
3. 앱의 `성능 테스트 웹사이트`를 엽니다: https://tapbench-click-lab.la123923769834767360.chatgpt.site
4. 웹사이트에 앱과 같은 총 목표 속도·방식을 설정하고 `측정 준비`를 누릅니다.
5. 1번 위치에서 **⌃⌥S**, 2번에서 **⌃⌥D**, 3번에서 **⌃⌥F**를 누릅니다. 선택한 지점을 모두 지정해야 시작합니다.
6. **⌃⌥Space**로 시작합니다. 3초 뒤 순환 클릭하며, 같은 단축키로 중지합니다.

실행 시간은 1–3,600초입니다. 화면 구성 변경, 잠자기, 세션 변경 시 정지합니다. 창을 옮기거나 스크롤했다면 좌표를 다시 지정하세요.

## 성능 측정

**40,000 CPS는 요청 설정이며 실제 수신 보장값이 아닙니다.** 1.2.1의 두 지점·1,000 CPS 설정에서는 GitHub macOS VM/WebKit 녹화 중 실제 평균 963.4 CPS를 확인했습니다. 이는 이번 세 지점·40,000 CPS 설정의 결과가 아닙니다. 이번 결과는 해당 Release의 `actual-received.json`과 영상으로 확인하세요.

높은 요청량은 대상 앱의 처리를 지연시켜 실제 수신 속도를 낮출 수 있습니다. 목표를 바꾸어 웹사이트가 받은 CPS를 비교하세요. 앱의 전송 속도는 macOS에 보낸 요청으로, 웹 수신 수와 다릅니다. 중지한 뒤 이미 OS에 보낸 이벤트가 늦게 도착할 수 있습니다.

고속 모드는 실행 시점이 된 요청을 최대 32쌍씩 전송합니다. 기존 방식은 콜백마다 한 쌍만 보냅니다. 오래 밀린 요청은 건너뛰며, 실행 시간이 끝나면 새 쌍을 보내지 않습니다. OS 전송 중에도 상태 조회는 가능하고, 중지는 진행 중인 한 쌍이 끝난 후 반환합니다.

## 빌드와 검증

GitHub Actions `macOS DMG`에서 스케줄·엔진 검사, arm64/x86_64 컴파일, 서명 구조 검사, DMG 무결성 검사를 실행합니다. 검사는 40,000 총 예산, 세 지점 순환·균등 배분, 중지·재시작, 최대 시간 계산과 전송 지연 중 상태 조회를 포함합니다. 가짜 출력 검사의 처리량을 실제 클릭 성능으로 보고하지 않습니다.

`macOS actual input video`는 동일 소스로 빌드한 생산용 앱을 실제 실행하여, 세 지점·40,000 목표 설정의 수신 결과와 화면 녹화를 생성하고 테스트한 DMG/ZIP과 함께 Release에 게시합니다. 촬영은 CI에서만 수행하며 앱에는 녹화 기능이 없습니다.

이 빌드는 ad-hoc 서명된 테스트 앱이며 Apple Developer ID 서명 및 공증은 없습니다. macOS가 차단하면 시스템 설정 → 개인정보 보호 및 보안에서 해당 앱의 `확인 없이 열기` 절차를 사용할 수 있습니다.

앱은 전역 단축키만 등록하며 키 입력 기록, 화면 캡처, 원격 전송을 하지 않습니다. Android의 별도 변경은 유지합니다.

로컬 빌드: Xcode Command Line Tools가 있는 Mac에서 `bash macos/scripts/build.sh`.
