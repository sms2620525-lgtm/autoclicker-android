# TapBench 1.2.0 for macOS — 두 지점 고속 클릭

macOS 13 이상, Apple Silicon과 Intel Mac을 지원하는 네이티브 오토클릭커입니다.

## 1.2.0 변경

- **고속 모드가 기본**입니다. 클릭마다 타이머 콜백을 기다리지 않고, 한 콜백에서 이미 실행 시점이 된 클릭을 최대 32쌍까지 전송합니다. 고속 타이머 간격은 최소 0.5ms입니다. 미래의 클릭을 미리 전송하거나 오래 밀린 요청을 끝없이 재생하지 않습니다.
- 기본 총 목표는 **10,000 CPS**, 설정 상한은 **20,000 CPS**입니다. 이는 요청 속도이며 실제 수신 속도를 보장하지 않습니다.
- `기존 방식`은 콜백마다 최대 한 쌍만 전송합니다. 두 모드에 같은 목표 속도를 넣고 웹사이트의 실제 수신 CPS를 비교할 수 있습니다.
- 한 쌍을 전송할 때마다 종료 시간을 확인하고, 쌍 사이에서 중지 요청을 받을 수 있습니다. 중지 후 이전 실행의 콜백은 새 실행에 영향을 주지 않습니다.
- JSON 전송 기록 v3에 앱 버전과 모드를 추가했습니다. Android의 별도 3지점·90,000 목표 상한 변경은 그대로 유지합니다.

## 사용

1. DMG를 열고 TapBench.app을 Applications로 드래그합니다.
2. 앱의 `권한 설정`을 누르고 시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용에서 TapBench를 허용합니다. 업데이트 후 권한이 인식되지 않으면 해당 앱 항목을 다시 허용하세요.
3. 앱의 `성능 테스트 웹사이트`를 엽니다: https://tapbench-click-lab.la123923769834767360.chatgpt.site
4. 웹사이트에서 앱과 같은 **총 목표 속도**를 설정하고 `측정 준비`를 누릅니다.
5. 1번 영역에 포인터를 놓고 **Control + Option + S**, 2번 영역에서는 **Control + Option + D**로 위치를 지정합니다. 앱의 `3초 후 지정` 버튼도 사용할 수 있습니다.
6. **Control + Option + Space**로 시작합니다. 3초 뒤 1 → 2 → 1 → 2 순서로 클릭하며, 같은 단축키로 중지합니다.

기본값은 `2개 교대 / 고속 / 총 10,000 CPS / 10초`입니다. 두 위치를 모두 지정해야 시작합니다. `1개`를 선택하면 첫 위치만 클릭합니다. 두 지점에서 총 10,000 CPS이면 지점당 목표는 약 5,000 CPS입니다. 두 곳을 동시에 누르는 멀티터치가 아닙니다.

실행 시간은 1–3,600초입니다. 화면 구성 변경, 잠자기, 세션 변경 시 정지합니다. 창을 옮기거나 스크롤했다면 좌표를 다시 지정하세요. 웹 측정은 첫 클릭부터 시작하며, 브라우저 탭을 바꾸면 중단됩니다.

## 속도 비교

`기존 방식`과 `고속`을 **같은 목표·시간·좌표**에서 각각 실행하세요. 웹사이트에 기록되는 총 수신 CPS와 1번/2번 수신 횟수를 비교하세요. 먼저 5,000, 다음 10,000, 필요하면 20,000 목표로 올려 보세요. 목표를 올려도 수신 CPS가 늘지 않으면 그 앱/시스템의 처리량이 제한된 것입니다.

앱의 `전송 속도`는 macOS에 보낸 mouse-down/up 쌍입니다. 운영체제나 대상 앱에서 처리·누락될 수 있어 실제 수신 수와 다릅니다. 고속 모드는 짧은 묶음으로 전송하므로 클릭 간격이 균등하지 않을 수 있습니다. 중지하면 앱은 더 이상 새 쌍을 전송하지 않지만 이미 macOS에 보낸 이벤트가 나중에 전달될 수 있습니다.

## 배포와 검증

GitHub Actions `macOS DMG`가 Swift 앱을 arm64와 x86_64로 컴파일해 universal binary를 만듭니다. 스케줄 검사, 가짜 출력으로 실행하는 엔진 검사(교대·배치 상한·시간 종료·동시 중지·재시작), 코드 서명 구조 검사, DMG 무결성 검사 후 Release에 DMG/ZIP/검증 기록을 게시합니다.

CI의 가짜 출력 검사는 실제 마우스 이벤트를 발생시키지 않습니다. 실제 Mac의 수신 성능이나 손쉬운 사용 허용은 자동 검증하지 않으며, 사용자 Mac과 대상 브라우저에서 측정해야 합니다. 고속 모드의 실제 배수 향상을 미리 주장하지 않습니다.

이 빌드는 ad-hoc 서명된 테스트 앱이며 Apple Developer ID 서명 및 공증은 없습니다. macOS가 차단하면 시스템 설정 → 개인정보 보호 및 보안에서 해당 앱의 `확인 없이 열기` 절차를 사용할 수 있습니다. 시스템 전체 보안 기능을 끄지 마세요.

앱은 전역 단축키만 등록하며 키 입력 기록, 화면 캡처, 원격 전송을 하지 않습니다. 전역 단축키를 등록하지 못하면 시작하지 않습니다.

로컬 빌드: Xcode Command Line Tools가 있는 Mac에서 `bash macos/scripts/build.sh`.
