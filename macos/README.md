# TapBench 1.2.1 for macOS — 두 지점 실제 수신 성능 개선

macOS 13 이상, Apple Silicon과 Intel Mac을 지원하는 네이티브 오토클릭커입니다.

## 1.2.1 변경

- 기본 총 목표를 **1,000 CPS**로 조정했습니다. GitHub macOS VM / WebKit에서 기존 고속 모드의 10,000 CPS 요청은 실제 18.8 CPS, 1,000 CPS 요청은 실제 662.5 CPS였습니다. 지나치게 많은 이벤트를 보내면 대상 앱의 수신 처리량이 오히려 떨어졌습니다. 이는 CI 엔진 진단 결과이며, 녹화가 포함된 실제 앱 결과는 별도 Release의 `actual-received.json`에서 확인합니다.
- 자주 쓰는 속도 버튼을 500 / 1,000 / 5,000으로 변경했습니다. 직접 입력하는 상한은 20,000 CPS입니다. 설정값은 요청 목표이며 실제 수신 속도를 보장하지 않습니다.
- OS 전송 중에도 앱이 상태를 조회할 수 있도록 동기화를 분리했습니다. 중지는 진행 중인 down/up 한 쌍이 끝난 뒤 반환하므로 중지 완료 후 새 쌍이 전송되지 않습니다.
- CI에서 생산용 앱을 빌드한 뒤 그 앱을 실제 실행해 촬영하고, **테스트한 동일 앱의 DMG/ZIP**과 측정 결과를 함께 게시합니다. 앱에는 촬영 기능을 추가하지 않았습니다.

## 사용

1. DMG를 열고 TapBench.app을 Applications로 드래그합니다.
2. 앱의 `권한 설정`을 누르고 시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용에서 TapBench를 허용합니다.
3. 앱의 `성능 테스트 웹사이트`를 엽니다: https://tapbench-click-lab.la123923769834767360.chatgpt.site
4. 웹사이트에 앱과 같은 **총 목표 속도와 클릭 방식**을 선택하고 `측정 준비`를 누릅니다.
5. 1번 영역에 포인터를 놓고 **Control + Option + S**, 2번 영역에서는 **Control + Option + D**로 위치를 지정합니다.
6. **Control + Option + Space**로 시작합니다. 3초 뒤 1 → 2 → 1 → 2 순서로 클릭하며, 같은 단축키로 중지합니다.

기본값은 `2개 교대 / 고속 / 총 1,000 CPS / 10초`입니다. 두 지점의 합계가 목표 속도이며, 두 곳을 동시에 누르는 멀티터치가 아닙니다. `1개`를 선택하면 첫 위치만 클릭합니다. 실행 시간은 1–3,600초입니다.

화면 구성 변경, 잠자기, 세션 변경 시 정지합니다. 창을 옮기거나 스크롤했다면 좌표를 다시 지정하세요. 웹 측정은 첫 클릭부터 시작하며, 브라우저 탭을 바꾸면 중단됩니다.

## 실제 속도 확인

500 → 1,000 → 5,000 순으로 비교하고 **웹사이트가 받은 CPS가 가장 높은 설정**을 선택하세요. `고속`은 콜백마다 밀린 요청을 최대 32쌍까지 보냅니다. `기존 방식`은 콜백마다 한 쌍만 보냅니다. 두 방식 모두 오래 밀린 요청은 건너뛰고, 실행 시간이 끝나면 더 이상 보내지 않습니다.

앱의 `전송 속도`는 macOS에 보낸 요청입니다. 운영체제나 대상 앱에서 누락되거나 지연될 수 있어 실제 수신 수와 다릅니다. 중지 후 이미 OS에 보낸 이벤트가 나중에 도착할 수 있습니다. GitHub VM 및 녹화 부하는 사용자 Mac과 다르므로 CI 수치를 모든 Mac의 성능으로 보장하지 않습니다.

## 배포와 검증

GitHub Actions `macOS DMG`는 스케줄 검사와 엔진 검사, arm64/x86_64 컴파일, 서명 구조 및 DMG 무결성 검사를 실행합니다. `macOS actual input video`는 같은 검사를 거친 실제 앱과 웹 수신 측정을 화면 녹화하고 DMG/ZIP/영상/측정 JSON을 Release에 함께 게시합니다. `macOS input pipeline diagnostic`은 별도의 CI 엔진 진단입니다.

가짜 출력으로 실행하는 단위 검사는 교대·배치 상한·시간 종료·동시 중지·재시작·OS 전송 지연 중 상태 조회를 확인합니다. 실제 CPS 증거는 실제 입력 테스트 결과만 사용합니다.

이 빌드는 ad-hoc 서명된 테스트 앱이며 Apple Developer ID 서명 및 공증은 없습니다. macOS가 차단하면 시스템 설정 → 개인정보 보호 및 보안에서 해당 앱의 `확인 없이 열기` 절차를 사용할 수 있습니다. 시스템 전체 보안 기능을 끄지 마세요.

앱은 전역 단축키만 등록하며 키 입력 기록, 화면 캡처, 원격 전송을 하지 않습니다. 전역 단축키를 등록하지 못하면 시작하지 않습니다. Android의 별도 변경은 유지합니다.

로컬 빌드: Xcode Command Line Tools가 있는 Mac에서 `bash macos/scripts/build.sh`.
