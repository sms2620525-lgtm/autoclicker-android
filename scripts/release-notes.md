Android 7.0 이상용 네이티브 오토클릭커 테스트 APK입니다.

- **TapBench-1.0.0-debug.apk**: 설치 파일
- **SHA256SUMS.txt**: APK SHA-256
- **TapBench-test-results.zip**: 단위 테스트, Lint, 기기 테스트 결과

초당 90,000회(제스처)는 설정 가능한 목표이며 Android 실제 터치 속도를 보장하지 않습니다. 지점 3곳을 동시에 누르므로 완료 제스처 1회는 탭 3회입니다. 앱에서 접근성을 켠 뒤 성능 테스트를 실행하면 실제 수신 CPS를 볼 수 있습니다. CI 성공 여부는 이 릴리스의 커밋에 연결된 Actions에서 확인하세요. 기기 테스트가 실패해도 디버깅용 APK와 가능한 보고서를 보존합니다.

테스트용 debug 서명입니다. 이전 CI APK와 서명이 다르면 이전 앱을 제거하고 설치해야 합니다.
